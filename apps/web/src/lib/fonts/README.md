# Vendored web fonts

These files are copied from the official Google Fonts repository so Next.js
production builds do not need to fetch Google Fonts at build time. The layout
imports preserve the previous families, CSS variable names, and selected
weights.

Source repository: <https://github.com/google/fonts/tree/main/ofl>
